# Security Policy

## Reporting a vulnerability

Please do not publish security-sensitive details in a public issue. Until a dedicated private reporting contact is published, use GitHub's private vulnerability reporting feature if it is enabled for this repository.

Please include the affected version, browser, reproduction steps, and potential impact. Do not include passwords, account tokens, private chart links, or personal trading data.

## Scope

SyncCharts is a local browser extension. It runs its content scripts on TradingView pages and exchanges synchronization messages between open TradingView tabs. It does not operate a SyncCharts cloud service.
