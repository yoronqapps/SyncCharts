# Privacy Policy

_Last updated: November 5, 2026_

SyncCharts is a browser extension that synchronizes TradingView chart crosshairs between tabs.

## Information processed

While TradingView pages are open, SyncCharts processes chart interaction data needed for synchronization, including the hovered candle timestamp and the pointer's relative vertical position. This information is passed between TradingView tabs in the same browser.

SyncCharts stores the user's selected time-label format (12-hour or 24-hour) in the browser's local extension storage.

## Collection and sharing

SyncCharts does not operate an account system or a SyncCharts cloud server. It does not intentionally transmit synchronization data to the extension developer or to third-party analytics, advertising, or tracking services.

TradingView itself remains subject to TradingView's own privacy policy and practices when the user visits its website.

## Permissions

The extension requests access to TradingView tabs so it can identify open chart tabs and synchronize them. It uses browser extension storage to retain the time-label preference. Its page scripts run on TradingView pages only.

## Changes

This policy may be updated if the extension's behavior changes. Any revised policy should be published alongside the corresponding release.

## Contact

For privacy questions, please open an issue in the official SyncCharts source repository once its public repository URL is published.
